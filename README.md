# twitch-village-mvp

OBS-оверлей для стрима: зрители чата отображаются персонажами внизу экрана.
Первое сообщение в чате вызывает игрока. Профили зрителей хранятся в локальной
SQLite, привязаны к каналу и переживают перезапуск виджета.

## Команды чата

| Команда     | Алиас       | Действие                              |
| ----------- | ----------- | ------------------------------------- |
| `!bots [N]` | `!боты [N]` | добавить N ботов (только модераторам) |
| `!unbots`   | `!боты-`    | убрать ботов (только модераторам)     |
| `!chop`     | `!рубить`   | зритель рубит деревья                 |
| `!plant`    | `!сажать`   | зритель сажает растения               |
| `!mine`     | `!шахта`    | зритель добывает камни\руду           |
| `!me`       | `!я`        | эффект выделения зрителя (кд 30 мин)  |

Работа продолжается, пока задание не снято через `cancelJob(userId)`.

## Кулдауны

Политики описаны в `COOLDOWNS` (`src/lib/chat/config.ts`), команды ссылаются на
них по id. `scope: "user"` — кд на зрителя, `"global"` — общий на команду.
Одинаковый id у нескольких команд создаёт группу с общим кд. Отказ проходит
молча; модераторы обходят кд, если у политики `exemptMods: true`.

## Новые эффекты

Эффекты описываются в `src/lib/game/effects/catalog.ts` и исполняются раннером
`effects/runner.ts`. Описание — список фаз; внутри фазы действия идут
параллельно. Готовые действия лежат в `effects/actions.ts`: панорама камеры,
зум, затемнение фона и проигрывание pixelfx. Пиксель-эффекты регистрируются в
`src/lib/game/fx/catalog.ts`.

Фоновые эффекты привязаны к позиции карты и живут, пока их не остановили: их
описывают `ambient: true` и фаза с бесконечной длительностью. Костёр запускается
через `game.spawnEffect({ id: CAMPFIRE_EFFECT_ID }, CAMPFIRE_POSITION)` и
отображается в слое карты, поэтому следует за камерой. Чатовые эффекты привязаны
к зрителю и запускаются через `game.playEffect(id, userId)`.

## Ассеты

Персонаж зрителя и животные берутся из бесплатного пака Cute Fantasy Free.
Лицензия пака запрещает перераспределение, поэтому архив и распакованные файлы
не лежат в репозитории.

Перед запуском скачай пак с
[страницы автора](https://kenmi-art.itch.io/cute-fantasy-rpg) и распакуй его в
`static/`.

## Разработка

```sh
pnpm install
pnpm dev       # http://localhost:5173
```

## Локальный сервер

```sh
pnpm build
pnpm start     # http://localhost:3000
```

Переменные окружения (см. `.env.example`): `SQLITE_PATH` (по умолчанию
`data/app.db`), `PORT`, `ORIGIN`, `LOG_LEVEL`.

## OBS

Добавь Browser Source с адресом `http://localhost:3000/`. Канал задан константой
`TWITCH_CHANNEL` в `src/lib/game/config.ts`. Фон страницы прозрачный; размеры
окна задаются в OBS. Масштаб персонажей можно задать параметром `viewer_scale`
(0.5–6), например `http://localhost:3000/?viewer_scale=3`.
