# twitch-village-mvp

OBS-оверлей для стрима: зрители чата отображаются персонажами внизу экрана.
Первое сообщение в чате вызывает игрока. Профили зрителей хранятся в локальной
SQLite, привязаны к каналу и переживают перезапуск виджета.

## Команды чата

| Команда     | Действие                              |
| ----------- | ------------------------------------- |
| `!боты [N]` | добавить N ботов (только модераторам) |
| `!боты-`    | убрать ботов (только модераторам)     |

## Ассеты

Персонаж зрителя и животные берутся из бесплатного пака Cute Fantasy Free.
Лицензия пака запрещает перераспределение, поэтому архив и распакованные файлы
не лежат в репозитории.

Перед запуском скачай пак с
[страницы автора](https://kenmi-art.itch.io/cute-fantasy-rpg) и распакуй его в
`static/`.

## Разработка

```sh
pnpm install
pnpm dev       # http://localhost:5173
```

## Локальный сервер

```sh
pnpm build
pnpm start     # http://localhost:3000
```

Переменные окружения (см. `.env.example`): `SQLITE_PATH` (по умолчанию
`data/app.db`), `PORT`, `ORIGIN`, `LOG_LEVEL`.

## OBS

Добавь Browser Source с адресом `http://localhost:3000/`. Канал задан константой
`TWITCH_CHANNEL` в `src/lib/game/config.ts`. Фон страницы прозрачный; размеры
окна задаются в OBS. Масштаб персонажей можно задать параметром `viewer_scale`
(0.5–6), например `http://localhost:3000/?viewer_scale=3`.
